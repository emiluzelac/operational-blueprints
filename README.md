# Operational Blueprints

This repository is a public home for operational guidance, training procedures, and agent-facing playbooks that can be shared and reused.

## What is in this repository?

- A public reference version of the long-running model training operations blueprint.
- A place to preserve operational instructions that are useful for both humans and coding agents.
- A simple structure for sharing reproducible workflows and safety practices.

## Contents

- [Long-running model training operations blueprint](docs/operational-blueprints/long-running-training-blueprint.md)
- [License](LICENSE)

## Purpose

The goal of this repository is to make useful operational practices easy to publish, review, and reuse. The blueprint here focuses on:

- safe long-running training operations
- evidence-based monitoring and verification
- deterministic watchdog behavior
- reproducibility and change control
- clear release and evaluation gates

## Recommended use

This repository can be used as a public reference copy of operational instructions. In practice, the same guidance can also be embedded into an agent's system instructions or repository-specific Copilot instructions for day-to-day use.
